Speeds are line rate in Mbit/s (payload plus TCP/IP/Ethernet headers, so a gigabit link can read close to 1000), measured over several parallel streams, with the first seconds of each phase left out while the link ramps up. Latency is the time from sending a small HTTPS request to the first byte of the reply (browser request timing, so it includes the server's own response time), on an idle link, after two warm-up requests. Run history is stored in this browser only. Options in the URL: ?dl=10&ul=10&ping=30 (seconds, seconds, requests) and ?auto to start at once.
